localSpace 0.2.0. Everything runs on your computer, and nothing you type leaves it.

## What's new

- **Attach text files.** Add a .txt, .md or .csv file, or code, up to 2 MB, and ask about it. A file longer than the chat has room for is read from its start, and the message says how much the model read.
- **Pictures in chat.** Attach a picture with the paperclip, drag it onto the message box, or paste a screenshot with Ctrl+V. The model you use has to be one that reads pictures (Qwen3.5 4B and 9B).
- **Maths shows as formulas.**
- **A model chosen for your computer.** The app looks at your graphics card and memory, and starts with the model that runs well there. On a laptop with 16 GB of memory and a 4 GB graphics card, that is Qwen3.5 4B.
- **Answers in your language and alphabet.** Ask in Russian, Uzbek (Latin or Cyrillic) or English, and the answer comes back the same way.
- **The app in Russian and Uzbek, in part.** Choose the language in Settings → General. The messages about attachments and about how an answer ended are translated; most screens are still in English.
- **Newer models in the list:** Qwen3.5 and Gemma 4. Each entry shows who made it, and the list is grouped by how well a model will run on your computer.
- **You always see why an answer ended early:**
  - it reached its length limit: **Continue** carries it on;
  - it started repeating itself, so it was stopped;
  - the chat is full: start a new chat;
  - your message is too long for the model: send a shorter one, or attach the text as a file.
- **When a model thinks before it answers,** you see that it's thinking, and for how long.
- **The cursor stays in the message box,** so you can type without clicking.
- **The Help page links to our Telegram group,** which opens in your browser. Nothing is sent from the app.

## Changed

- **Qwen2.5 models are no longer offered.** If you have one, it stays in your list as an older model. You can keep using it or delete it.
- **No more empty chats** in the list.
- **The whiteboard and the planner are gone from this version.** If you had them, nothing of yours is deleted.
- **"Choose a model" and the network status at the top** open the right page of Settings.

## Fixed

- An engine left running after the app closed no longer stays behind.

## Known issues

- **The installer isn't signed.**
  - If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**.
  - If Smart App Control blocks it, there is no way past that message. Please keep Smart App Control on.
  - Check your download against its SHA-256 below.
- **The installer downloads nothing.** Windows 11 includes WebView2 and most Windows 10 computers already have it; if yours doesn't, localSpace tells you, and its button opens Microsoft's page in your own browser.

## Downloads

- `localSpace-0.2.0-…-windows-x64-setup.exe`: the installer.
- `localSpace-0.2.0-…-windows-x64-portable.zip`: the same app, unpacked into a folder of your choice.
- Each file's SHA-256 is in `SHA256SUMS.txt`. To check a file, open PowerShell in your Downloads folder and run `Get-FileHash .\<file> -Algorithm SHA256`; if the two values differ, don't run it.

The licences of everything localSpace includes are in `licences\THIRD-PARTY-NOTICES.txt` beside the app.
