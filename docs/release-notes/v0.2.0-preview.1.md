**Preview.** This is a preview of localSpace 0.2.0, for you to try before the release. localSpace 0.2.0 follows after its release check in November. Everything runs on your computer, and nothing you type leaves it.

## What's new

- **Pictures in chat.** Attach a picture with the paperclip, drag it onto the message box, or paste a screenshot with Ctrl+V. Up to 4 pictures can go with one message. The model you use has to be one that reads pictures (Qwen3.5 4B and 9B, Gemma 4 E2B and E4B). If your computer's memory is short, the app says how much more it needs, with **Try again**, and suggests a model that fits when there is one.
- **A model chosen for your computer.** On a laptop with 16 GB of memory and a 4 GB graphics card, localSpace now starts with Qwen3.5 4B. It leaves room for your browser and other programs.
- **Long chats stay quick.** When a chat grows past what the model can read at once, its oldest messages are left out in one step, and a line in the chat says so. Every message stays in the chat for you.
- **Less memory in long chats.** The model's engine now keeps far less in memory as a chat goes on.
- **Messages in your language.** The new messages about pictures and memory are in English, Russian and Uzbek, following Windows' display language. You can change it in Settings → Language.
- **Maths shows as formulas.**
- **Newer models in the list**, including Gemma 4 E2B and E4B. Qwen2.5 models are no longer offered. If you have one, you can keep using it or delete it.
- **Help → Send feedback** opens our Telegram group in your browser. Nothing is sent from the app.

## Known issues

- **No text files yet.** Attaching text files, PDFs and Word documents comes in a later version.
- **The installer isn't signed yet.**
  - If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**.
  - If Smart App Control blocks it, there is no way past that message. Please keep Smart App Control on, and wait for a signed version.
  - Check your download against its SHA-256 below.
- **Very long chats:** once in a while the first word of an answer takes longer, a few seconds on a laptop with a 4 GB graphics card, when older messages are left out. Going back to an older long chat can take about 12 seconds the first time.
- **This preview runs on the standard (Vulkan) engine only.** An NVIDIA edition comes later.

## Measured

Qwen3.5 4B ran at about 6–7 tokens a second (English answers) on an 8 GB laptop with Intel Iris Xe graphics and no NVIDIA card, with a browser and VS Code open.

## Downloads

- `localSpace-0.2.0-…-windows-x64-setup.exe`: the installer.
- `localSpace-0.2.0-…-windows-x64-portable.zip`: the same app, unpacked into a folder of your choice.
- Each file's SHA-256 is in `SHA256SUMS.txt`. To check a file, open PowerShell in your Downloads folder and run `Get-FileHash .\<file> -Algorithm SHA256`; if the two values differ, don't run it.

The licences of everything localSpace includes are in `licences\THIRD-PARTY-NOTICES.txt` beside the app.
