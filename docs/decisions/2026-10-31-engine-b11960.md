# 2026-10-31: the engine moves to llama.cpp b11960 on `main`

`release/0.2` keeps b10869.

- **Why b11960:** it's v0.8.0 (28 Oct 2026), the first release that runs LFM3 (llama.cpp #31252). A newer build is taken only if the engine test finds a fault that a later build fixes.
- **The file:** `llama-b11960-bin-win-vulkan-x64.zip`, 37,345,851 bytes, at the SHA-256 that the release publishes.
- **What changed since b10869 (v0.4.1 to v0.8.0), read from the release notes and the source at the tag:**
  - `--mmap`/`--mlock`/`--direct-io` are gone. Core already passes `--load-mode`.
  - The default port is now 9931. Core always passes `--port`.
  - `/apply-template` still answers `prompt` as one string.
  - The chat layer was rebuilt (`common_chat_session`, v0.7.0). Streaming, tool calls, thinking and Continue are measured again.
  - Picture resizing changed (v0.8.0). Each picture model's cost is measured again.
- **Qwen3 30B A3B and gpt-oss 120B are hidden on `main`:**
  - they're too large for the machine the engine test runs on, so they can't be measured again;
  - gpt-oss's chat format is the most exposed to the rebuilt chat layer;
  - they're measured again on a machine large enough, then shown again.
- **Before a build with this engine reaches anyone:** `docs/BUILD.md`, "When the pin moves", through the engine test.
