# 2026-10-31: 0.3.0-preview.1

The first preview of 0.3.0, built from `main`.

- **The version is 0.3.0** in `Cargo.toml` and `tauri.conf.json`, so that the tag `v0.3.0-preview.1` names it (`scripts/check-version.mjs`).
- **The preview channel turns on `themes` and `lfm3`.**
  - Every other unfinished feature stays off, `translation` included.
  - `dev` and `stable` stay off.
- **`package.yml` gives a build its channel from the tag:** `v*-preview.N` is built as `preview`; any other tag, or a build by hand, as `stable`. Core reads it as `LOCALSPACE_CHANNEL` when it is compiled (`features::channel`).
- **Before it is published:** the release check runs on the tag's own package, updating from v0.2.0. The engine test ran on the same engine and catalog ([2026-10-31-engine-test.md](2026-10-31-engine-test.md)).
- **Test:** `only_the_preview_turns_features_on` (`features.rs`).
