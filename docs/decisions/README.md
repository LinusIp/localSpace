# Decisions

One file per decision, named `YYYY-MM-DD-topic.md`. Each file gives the date, the decision, the section of the specification it affects, and the tests that hold it. A decision lands in the same commit as the code that uses it.

The file names sort by date. Decisions before 2026-10-31 are in [`../DECISIONS.md`](../DECISIONS.md), which is frozen.
